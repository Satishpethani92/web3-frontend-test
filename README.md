# ©Tirios — Web3 Frontend Development Assessment

Thank you for your interest in joining **Tirios**.

This assessment is designed to evaluate your skills in **Web3 integration, frontend development, wallet connectivity, state management, and interactive user experiences**.

## Task

Implement a functional **MetaMask wallet connection** in the existing project. The current **Connect Wallet** button is a placeholder and should be updated to provide a complete wallet connection experience.

### Requirements

* Implement **MetaMask integration** using `window.ethereum`
* Allow users to connect their MetaMask wallet
* Display the connected wallet address in a user-friendly truncated format

  * Example: `0x1234...5678`
* Listen for **MetaMask account changes**
* Automatically update the UI when the connected account changes
* Handle common errors, including:

  * MetaMask is not installed
  * User rejects the connection request
  * Network or provider errors
* Maintain a clean and intuitive user experience
* Preserve the existing functionality of the project

Feel free to make reasonable UI/UX improvements where appropriate.

## Technology

Use the existing project stack and integrate with the current implementation.

You may use **React, Next.js, JavaScript, TypeScript, ethers.js, wagmi, or other appropriate libraries**.

Please avoid unnecessary changes to the project's architecture or technology stack.
